This Space is a static landing page for **redline-tiny**, which runs Qwen-Image-2.1-Turbo (image editing and text-to-image, 1024x1024) on the AMD Ryzen AI NPU of a Windows laptop. An NPU can't run on Spaces, so there is no live demo here.

- Code: https://github.com/Cukrus-directive/redline-tiny
- Compiled NPU programs: https://huggingface.co/cukrus/redline-tiny-npu
